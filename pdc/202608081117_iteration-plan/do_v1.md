1. 完整阅读审查报告（374 行）：获取 5 类不足（A-E）、P0-P8 迭代方向、Top 5 推荐行动、现有 ROADMAP 评估、ROADMAP 遗漏方向

4. 完整阅读 COMPARISON.md（134 行）：确认竞品对比现状（用于差异说明章节）

### 版本-P 映射

采用任务上下文中建议的版本-P 映射：
- v1.18 = P0 文档同步与治理（M，低风险）
- v1.19 = P1 CI/CD + P2 测试扩充（L，低风险，合并）
- v1.20 = P3 错误处理 + P4 代码重构（L，中/低风险，合并）
- v1.21 = P5 EXIF 写入与元数据扩展（L，中风险）
- v2.0 = P6 wasm 渐进支持（XL，高风险）
- v2.1 = P7 性能优化 + P8 API 人体工程学（XL+L，中/高风险，合并）

### 工作量口径转换

采用任务上下文定义的 S/M/L/XL 口径（S≤2、M=3-5、L=6-10、XL>10 人日），对每个功能项标注工作量等级。

### 关键决策

1. **合并原则应用**：P1+P2（CI 与测试相互支撑）、P3+P4（错误处理为重构提供安全网）、P7+P8（同属长期探索）合并到同一版本，符合合并原则（同优先级区间、总工作量≤L、无相互阻塞）
2. **v2.0 路径选择**：采用渐进路径（先 wasm fallback 子集）而非现有 ROADMAP 的二元选择，对应审查报告 P6 建议
3. **v2.1 重新定义**：将现有 ROADMAP 的 WebP/stream/TIFF/APNG 替换为 P7+P8（性能优化 + API 人体工程学），WebP/TIFF/APNG/流式解码移至"不做的事情"短期排除
4. **审阅检查清单**：列出 6 个关键决策点和 6 个优先级排序确认项，供用户审阅

### 格式兼容性

产出文档采用 Markdown，一级标题为文档标题，二级标题为版本/章节分节（`## v1.18`、`## 计划概述` 等），与现有 ROADMAP.md 标题层级一致（ROADMAP.md 中 `## v1.1`、`## v2.0`、`## 不做的事情` 等均为二级标题），内容可直接替换或追加到 ROADMAP.md 中而不破坏现有锚点结构。新增章节（审阅检查清单等）追加在末尾。
