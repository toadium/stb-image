- **MoonBit 编译器**: native backend, release mode
- **测试图像**: 128×128 RGB（resize 测试使用 256×256）

## 分析

### 性能分层

1. **超快 (<100 µs)**: crop, adjust_brightness, to_grayscale, rotate_90, BMP 编码
2. **快 (100-300 µs)**: edge_detect_sobel, QOI 编码, box_blur, sharpen, QOI 解码
3. **中等 (300-1000 µs)**: resize, PNG 编码, gaussian_blur, PNG 解码

### 瓶颈分析

- **PNG 解码** (956 µs) 是最慢操作，受 zlib 解压影响
- **gaussian_blur** (957 µs) 与 PNG 解码相当，可分离滤波已有优化
- **PNG 编码** (619 µs) 包含 zlib 压缩，预期较慢

### 对标参考

| 操作 | 纯 MoonBit (µs) | C stb_image 估计 (µs) | 比率 |
|------|-----------------|----------------------|------|
| PNG 解码 | 956 | ~200 | ~4.8x |
| PNG 编码 | 619 | ~150 | ~4.1x |
| resize | 491 | ~100 | ~4.9x |
| gaussian_blur | 957 | ~300 | ~3.2x |

> 注：C stb_image 估计值基于公开基准，实际比率取决于平台和编译器优化。
> 纯 MoonBit 约比 C 实现慢 3-5x，对于无 C FFI 的全目标支持是合理代价。

## 结论

纯 MoonBit 实现性能可接受，最慢操作（PNG 解码/gaussian_blur）约 1ms 级别。
对于服务端图像处理场景，吞吐量满足常见需求（17-284 MP/s）。
