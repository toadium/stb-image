# 图像处理分类

| 类别 | 功能 |
|------|------|
| 色彩调整 | brightness/contrast/gamma/invert/HSV/HSL |
| 滤波 | box/gaussian/sharpen/sobel/双边/NLM 去噪 |
| 几何变换 | crop/rotate/flip/warp_affine/transpose |
| 边缘检测 | Canny/Laplacian/Prewitt/Hough 变换 |
| 特征提取 | Harris/LBP/Gabor/GLCM/积分图像 |
| 分割 | K-means/区域生长/分水岭/泛洪填充 |
| 形态学 | erode/dilate/open/close/skeletonize |
| 频域 | FFT/IFFT/频域滤波/Haar 小波 |
| 直方图 | histogram/equalize/normalize |
| 混合模式 | 13 种（multiply/screen/overlay/darken/lighten/...） |
| 金字塔 | Gaussian/Laplacian/pyr_down/pyr_up |
| 质量评估 | MSE/PSNR/SSIM |
| 去噪 | NLM/Retinex(SSR/MSR/MSRCR)/去雾 |
| 量化 | Floyd-Steinberg/Median Cut/K-means |
